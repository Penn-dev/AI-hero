Anthropic 发布的模型上下文协议，正在 AI 领域迅速走红。

它就像 **AI 世界的 USB-C**，帮助面向用户的应用连接功能强大的 API。

把 Cursor 连到你的 GitHub 账户，把 Claude Desktop 连到你的邮箱。**可以做的事情没有尽头。**

译注：USB-C 是一种常见的连接接口。这里的比喻强调 MCP 提供了统一的连接方式。API 则是程序向另一个程序请求数据或操作的接口；真正接入账户仍需要相应工具及授权。

这套教程将介绍**开始交付 MCP 服务器所需的全部知识**。

我们会使用我最喜欢的语言 **TypeScript**，内容包括：

- 模型上下文协议为什么会出现。
- 怎样选择 MCP 客户端。
- 用 TypeScript 构建 MCP 服务器。
- 通过 NPM 分发 MCP 服务器。
- 在 serverless 平台上托管 MCP 服务器。

译注：NPM 是分发 JavaScript 和 TypeScript 相关软件包的平台。Serverless 通常译为无服务器计算，意思是由平台管理服务器的运行与资源，并不是实际没有服务器。

学完之后，你就能**把自己的 MCP 想法做成可交付的工具**，让世界各地的人都能使用。

前往 [AI Hero 的 GitHub 仓库](https://github.com/ai-hero-dev/ai-hero/)，获取全部代码并运行示例。
