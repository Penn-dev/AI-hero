## 用 TypeScript 交付现代 LLM 功能，从这里开始

你现有的 TypeScript 能力比以往更有价值，我会帮你进一步成长为 AI 工程师。

全新的 AI SDK v6 速成课包含 **94 段视频**，通过 **10 个模块**带你完成 **59 个动手练习**。别担心，练习有趣，完成也快。

你会扎实理解：

- **LLM 基础**，例如 Token 和上下文窗口到底怎样工作

- **面向生产的工具**，例如可观测性插桩与错误处理
- 怎样用**评估驱动开发**消除幻觉

没错，你可以从 “what is a token, anyway??”（Token 到底是什么？）开始，一步步交付真正能工作的生产级 LLM 功能，配备输出防护、消息持久化和错误处理。

**你只需要带上 TypeScript 基础**，其他所需内容都在课程里。

这也不是让你坐着、努力不走神的讲座。你了解我的，我不会这样上课。

你会通过构建真实项目来学习：

- **聊天标题生成器**，包含完整评估数据集

总之，你会做好准备，在 TypeScript 应用中规划、开发并上线面向生产的 AI 功能。

当然，技术和 AI SDK 本身还会继续演进。但有了这份面向真实场景、动手构建工具的经验，你也能跟着它们一起成长。

## 为什么 AI SDK 带来了根本改变，v6 又是迄今最好的一版

这门速成课实际上有两个目标：

1. 帮助你用现代工程原则交付 LLM 功能
2. 掌握 AI SDK v6 本身

强调第二点有原因：它既是抽象层，又是工程工具包，能省下大量工作。

保守估计，不用它，要达到相同的生产代码水平，你得投入两三倍工作，重复造轮子，还要应付平台变化。之后又没有开源社区帮你持续更新，未来工作只会更多。

在我看来，用 TypeScript 做 AI 开发却不用 AI SDK v6，是个错误。我甚至准备让 AI SDK 成为今后所有 AI Hero 课程的基础。

AI SDK 库能迅速达到每周 350 万次下载，是有原因的：

- **它是完全开源的应用工具包**。得益于宽松的 [Apache 2.0 许可](https://fossa.com/blog/open-source-licenses-101-apache-license-2-0/)，你可以复制、修改、派生，甚至按需要重新打包、重新许可。
- **它能与所有框架集成**。面向 TypeScript 和 JavaScript，为各大前端框架提供 Hooks，甚至也为原生 JavaScript 提供抽象。
- **它几乎支持所有 LLM，包括在自己硬件上运行的开源模型**。真的，可以查看[支持的提供商列表](https://ai-sdk.dev/docs/foundations/providers-and-models#ai-sdk-providers)。
- **一行代码就能切换模型**。因为所有 LLM 都有统一接口，切换模型或提供商就像修改配置一样简单。也可以在同一代码库中使用多个模型，仍然用统一命令。生态再怎么变化，你都能应对。
- **插桩很容易**。不必辛苦自己编写可观测性插桩，AI SDK 可以自动把 OpenTelemetry 数据导出到各大平台。
- **到处都能运行**。它不绑定平台，可以跑在 Deno、Bun、Node 上。虽然由 Vercel 开发，你仍可自由选择运行环境。
- **生态支持越来越广**。AI SDK 很受欢迎，原文这里写每周 300 万次下载，[Langfuse](https://langfuse.com/docs/observability/sdk/typescript/instrumentation)、[Braintrust](https://www.braintrust.dev/docs/integrations/vercel-ai-sdk) 等平台都已提供集成支持。我预计还会有更多平台加入。
