最近，我一直在用 TypeScript 和 AI 做各种东西：智能体、工作流、自定义脚本和命令行工具，帮助自己更快、更有效地工作。

Vercel AI SDK 是我的工具箱里非常好用的一件工具。

它是一个软件库，解决了与 LLM 打交道时的许多麻烦。

在这套教程中，我会完整介绍怎样上手使用它。

![Addy Osmani 的原头像](http://res.cloudinary.com/total-typescript/image/upload/v1737461573/posts/list-40v10/sopfsrvcgstoclcusbui.jpg)

Addy Osmani，Google Chrome 工程负责人：

“真的很不错！学到了几件我以前不知道的事。”

我们将介绍：

- 灵活切换模型。
- 流式输出。
- 结构化输出。
- 处理图片和文件。
- 工具调用。
- 构建智能体。

AI SDK Core 可以用在任何能运行 JavaScript 的地方，这也是我如此兴奋的原因。它用途广、能力强，而且对于几乎任何任务，都提供了恰到好处的抽象。

前往 [AI Hero 的 GitHub 仓库](https://github.com/ai-hero-dev/ai-hero/)，获取全部代码并运行示例。

译注：命令行工具通过输入命令使用；流式输出让结果逐步显示，结构化输出则按规定字段返回数据。原 Testimonial 与 HTML 清单已转为静态文字和列表，评价者身份、原头像和全部六项内容保留。本页是课程介绍，代码与教程运行未在本次验证。
