## From fuzzy idea to a workflow you trust

Each lesson is one skill and one small exercise on work you already have. Nothing here is theory you can't run the same afternoon.

1. 01

  ### Lesson 1: Choose your workflow path

  

  Start with reusable agent workflows instead of one-off prompts.
2. 02

  ### Lesson 2: Clarify the work with /grill-with-docs

  

  Find the fuzzy decisions before an agent starts building.
3. 03

  ### Lesson 3: Test uncertain ideas with /prototype and /handoff

  

  Make the unknown visible in a small, throwaway context.
4. 04

  ### Lesson 4: Turn decisions into /to-spec and /to-tickets

  

  Break large work into reviewable vertical slices.
5. 05

  ### Lesson 5: Run safer AFK agents with Sandcastle

  

  Scoped tasks, isolation, visible logs, and reviewable commits.
6. 06

  ### Lesson 6: Review the result with /code-review

  

  Find avoidable mistakes and improve the system around the diff.
7. 07

  ### Lesson 7: Put the full workflow together

  

  Run the loop from fuzzy idea to a better next agent run.
8. Lesson 7, what you'll have

  

  One written workflow, the slash commands that run it, and a review habit that keeps your codebase one an agent still performs well in.
