# 样本共享知识与教学配置

目前只覆盖AGENTS.md指南、Output练习、system prompt词条。内容由当前窗口根据已有材料整理，尚未代表全站知识地图，也未经过零基础读者验收。

- [共享配置](E:/dev/projects/AIHero/content/learning/pilot-knowledge.json)：三种内容模板、15个共享概念及三页的教学配置。`sources`记录依据和哈希，`concepts`记录定义、别名、概念依赖及出处，`pages`引用概念ID。
- [配置读取](E:/dev/projects/AIHero/lib/article-learning.ts)：合并共享定义与已有小词典。共享条目优先，同一概念使用稳定ID；未被覆盖的已有词条继续保留。
- [结构解析](E:/dev/projects/AIHero/lib/article-structure.ts)：使用与页面一致的Markdown解析器，不将代码中的标题当作目录；粗体、非粗体词条都可读取。只在展示层移除重复页标题、替换空的末尾视频文字稿标题，原译稿不变。
- [来源链接](E:/dev/projects/AIHero/lib/article-links.ts)：已提供中文的站内内容优先打开本地页面；其余回到英文原页并明确标识，避免进入不存在的中文页面。
- [校验入口](E:/dev/projects/AIHero/scripts/validate-learning-pages.mjs)：运行`npm run learning:validate`，检查出处、依赖、类型、原例和解析行为，不联网、不调用模型。

## 后续接入方式

1. 先确定文章属于指南、练习还是词典，并确认相应模板要求。不要仅凭篇幅认定为低风险。
2. 从已审概念中选取该文实际需要的定义和先备概念。新概念须附来源；`dependsOn`是理解顺序，不是网页链接清单。
3. 只在`pages`中补文章目标、准备条件或一句话定义、检查项及已有资源链接。页面组件不新增文章slug分支。
4. 原文代码、TODO与译文正文保持原样。自然语言原例可从来源逐字补入`originalExamples`，页面将它与原有中文理解放在相邻位置。
5. 来源变化时校验失败：先核实资产是否仍成立，再更新来源哈希。不能只改哈希让检查通过。

## 责任边界

脚本负责结构、复制、装配、解析和可达性；新增解释、概念依赖、练习提示的合理性需要语义判断及抽样验收。本阶段只验证公共能力与两页样本，不据此声称节省了Token。
