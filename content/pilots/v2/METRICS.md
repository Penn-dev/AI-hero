## 基于单一样本的 110 篇外推

已下载 Markdown 语料共有约 167,499 个源 Token。按当前样本的同比例外推：

| 阶段 | 输入 | 输出 |
| --- | ---: | ---: |
| Terra/medium | 249,590 | 258,413 |
| Sol/medium | 544,425 | 274,224 |
| 可观测内容载荷合计 |  | 1,326,651 |

按 Terra 输入 $2/百万、输出 $12/百万，Sol 输入 $4/百万、输出 $20/百万计算，API 等价最低费用约为 **$11.26**。本项目没有调用 API；该金额仅用于统一比较。

## 不能从本次运行精确获得的部分

- Agent 系统提示和项目级指令。
- 工具调用中模型实际读取的附加上下文。
- 内部 reasoning token。
- 失败重试和需要人工反馈后产生的返工。
- 不同文章类型导致的双语示例和术语小词典长度差异。

因此，1,326,651 tokens 和 $11.26 都是基于一个样本的“可观测最低外推”，不是最终整站预算。应先由用户验收样本质量，再决定是否需要更多代表性样本来缩小误差。
