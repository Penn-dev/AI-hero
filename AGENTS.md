## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues for `Penn-dev/AI-hero`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default Matt Pocock triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context layout with root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.

### Project workflow

Write requested handoff documents under `reports/handoffs/`; follow current user instructions and global authorization rules. See `docs/agents/workflow.md`.
