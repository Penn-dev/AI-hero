# 全站中文化制作规范

2026-10-13。当前制作入口，依据[规格 #1](https://github.com/Penn-dev/AI-hero/issues/1)与[项目定义](E:/dev/projects/AIHero/CONTEXT.md)。整合[样本规范](E:/dev/projects/AIHero/content/pilots/v2/STYLE_GUIDE.md)和[展示约定](E:/dev/projects/AIHero/content/learning/shared/display-conventions.md)中仍适用的要求；有冲突时以已确认规格为准。

## 范围与版本

首版使用[本次来源范围与缺口](E:/dev/projects/AIHero/reports/full-site/source-scope-2026-10-13.md)及其逐页清单，包含根页 `/`。只有本次实际取得、可核对正文与哈希的公开文字页面进入制作范围。历史数量、旧缓存或旧验收不代表本次取得或中文化完成。制作期间固定此版本；登录、付费、邮件课程、取得失败等缺口单列。

视频保留原视频和资源入口，不生成文字稿。公开课程介绍页、已取得的教程文字与未取得的课程视频、环境材料、练习或答案分别记录；介绍页取得不代表整套课程取得。没有运行验证，不声称代码可独立运行。

## 忠实而自然的中文

- 页面与原文一一对应。保留文章边界、标题层级、章节与步骤顺序、信息、作者观点、人称、语气和条件。直接教学表达保持直接，不统一改成“作者认为”；完整翻译，不摘要或省略。
- 先理解段落，再用自然中文表达。可拆长句、本地化习语；不改变论点、弱化语气或添加作者未作出的结论。以常见短句和主动语态消除歧义。
- 只补理解当前段落所需的背景，在相关段落附近明确标记“译注”。代码教程解释用途、关键步骤和必要准备；更完整的基础知识链接到相关中文页面。新增说明不得混作作者原文。
- 过时信息和疑似错误按原意翻译。仅对已可靠核实且会误导实际操作的内容添加“更新说明”，给出依据；不静默替换，也不为每句话另建核查流程。

## 术语、示例与资源

- 按需复用[已有术语表](E:/dev/projects/AIHero/content/glossary.json)和已有中文词条。正文以自然稳定的中文译名为主，首次正式解释核心概念可写“中文（English）”，后文用中文或已说明的简称，不反复堆双语括号。
- Token、LLM、API、SDK、MCP、Git、Markdown、AGENTS.md 等常用原名与标识符保留，必要时用白话解释。术语标题避免 Token（token）等重复；缩写可写“大语言模型（LLM）”。harness 使用“智能体执行框架（harness）”，system prompt 使用“系统提示词（system prompt）”。
- 原代码、命令、配置、文件名、API、标识符原样保留；中文解释放在外部。英文自然语言 Prompt 无论是否位于围栏中，都保留完整原块，紧邻附标为“中文版 Prompt”的完整可复制中文，不覆盖英文、不把它当作程序代码跳过。
- 英文对话示例按英文原例与对应“中文理解”成对呈现。附加译注放在完整示例之后，避免插到原例与理解之间。
- 保留原视频、图片、CTA（引导操作的文字及入口）和外部资源。组件的可见文字、链接及语义都要保留；展示包装可转为等价 Markdown。只翻译可见文案，保留技术属性、标识符和必要元数据；不执行或编造动态课程、注册、折扣、练习或答案材料。缺少可取得文字或入口时明确记缺项。
- HTML 恢复稿可能包含导航、作者信息、订阅表单、分享控件等页面外壳。对照原响应区分它们与文章教学正文；订阅与课程 CTA 保留文案和明确标为原站的入口，不将外壳误作教学内容，不虚构可用的本地表单。
- 保留 Frontmatter 键及 slug、type、tags、updatedAt 等技术值，翻译 title、description。输出完整 Markdown/MDX 文件，不套外层围栏。
- 站内概念链接优先使用已有中文页面，核对实际去向与解释覆盖。尚未制作的中文目标记录为待补，完成后再核对；不能把英文原页或空页当成已完成中文解释。原资源入口仍须保留且身份清楚。
- 辅助展示按文章需要使用，不强制每篇卡片、问答、文末词典或完整教学配置。使用已有术语组件时，词本身打开本页释义，独立的 ↗ 只跳可用中文页；问答使用独立 question、answer 字段。比较卡片窄屏单列，单数尾卡不留空占位。特殊组件、HTML 与折叠结构逐页核对，必要公共渲染问题交工程处理。

## 小批次制作与五项检查

通过 Codex 读取原文、制作或修订中文稿、检查完整页面并接页，暂不启用 API 翻译器。批次按文章完整性、长度与实际质量安排，不固定篇数或模型分工，不要求独立模型认证或每篇真人试读。

已有稿件先对照原文检查，合格部分保留，明确问题局部修订，大面积误译或遗漏才重做。基础概念可优先统一，但完整概念库和先修图谱不是生产前置。每批仅携带当前原文、此规范、必要术语和具体未决问题；记录完成页、问题位置、下一步及续接文件，交接遵循[项目工作流](E:/dev/projects/AIHero/docs/agents/workflow.md)。出现实质问题才返工，修正后检查受影响部分。

每篇记录以下五项实际结论与缺项，未执行的检查明确记“未验证”：

1. **信息完整准确**：逐节对照原文，无关键遗漏、误译、观点、人称、条件或顺序改变。
2. **中文自然**：通读完整中文稿，消除影响阅读的翻译腔和歧义，术语一致。
3. **必要概念讲清**：陌生关键概念有简短解释或可用中文词条；译注、更新说明身份明确，篇幅适度。
4. **代码与链接保真**：原代码、命令、配置与英文 Prompt 保留，中文 Prompt 完整可复制，对话附中文理解；中文目标和原资源、CTA 去向正确。
5. **页面正常显示**：真实打开最终页，检查正文、代码、资源入口及适用的复制、折叠、术语交互。首批及公共展示改动检查桌面与窄屏，无异常横向滚动；后续复用未受影响的展示证据，检查新内容特有结构。

语义判断由制作执行者对照原文与译稿完成；脚本、接页成功和构建不能替代语义或真实页面检查。全文、来源、检查记录及原地址层级页面齐备，才计入中文化完成。

## 后续更新

本轮固定来源后不反复全量同步。后续按需取得新增或变化页面，先核对原文差异，再更新译稿并重新检查受影响内容。来源丢失、教程材料或运行准备未验证的部分按页面披露。此入口服务当前制作，不扩大为历史文档重写、独立课程或平台建设；在线部署另行安排。
