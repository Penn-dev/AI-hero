# Project Workflow

## Handoffs

- Project handoff directory: `reports/handoffs/`
- Use this location for requested handoff documents.
- Preserve key decisions and link relevant source artifacts instead of duplicating them.

## Execution boundaries

Follow the user's current instructions and global authorization rules. Project configuration records destinations and conventions; it does not itself authorize publication, implementation, external writes, or delegation.

Authorization already given for the same task and scope remains valid for necessary coordination, verification, and correction.

Record additional project-specific restrictions here only when the user has established them.
