# AI Hero 全站中文化实施规格

2026-10-13。依据已完成的产品访谈与[项目定义](E:/dev/projects/AIHero/CONTEXT.md)。这是实施规格，尚未开始实施或批量制作内容。

## 目标与完成范围

交付可在本机稳定打开的 AI Hero 全站中文网站，供通过自然语言使用 Codex、没有代码基础的读者阅读。完整、忠实、自然地中文化原文，并补充理解当前内容所必需的背景说明。沿用现有页面样式、组件与原站内容体系。

正式生产前通过现有同步能力更新一次公开来源，记录日期、页面清单和来源哈希。第一版范围为此次清单中能稳定取得正文的全部公开文字页面；当前已有186篇只是历史数量，不作为固定目标。制作期间使用固定内容版本。无法取得的登录、付费、邮件课程等内容登记缺口；视频保留原视频及链接，不虚构文字稿。

每个范围内页面都有完整中文页、可追溯的原文和检查记录，页面可按原地址层级打开，才计入完成。来源取得失败的页面单列，不计作中文化完成。在线部署后续另行安排。

## 内容要求

- 页面与原文一一对应，保留文章边界、章节顺序、信息、作者观点、人称、语气与条件。不摘要，不用“作者认为”等转述统一替换直接教学表达。
- 按自然中文语序表达，可拆长句与本地化习语，但不改变论点、不增加作者未作出的结论。
- 简短背景说明放在相关段落附近并标记“译注”。Agent、Token、系统提示词、上下文窗口等跨篇概念优先复用中文词条；必要的本页解释可使用已有术语展示组件。
- 解释到读者能理解当前段落为止。代码教程交代用途、关键步骤和必要准备；更完整的基础知识通过相关页面链接补足。不要求每篇增加卡片、问答、词典或完整教学配置。
- 代码、命令、配置、标识符保留原样，必要说明放在外部。自然语言Prompt保留英文原版并附完整、可复制的中文版；英文对话示例附中文理解。源文中的自然语言Prompt即使位于围栏内也按Prompt处理：保留原块、另附中文，不覆盖原块。
- 保留视频及外部资源入口。站内概念链接优先指向已有中文页面，避免404；尚未完成的中文目标明确记录，不能把英文原页当作已完成中文解释。分批阶段的暂缺情况保留到目标页面完成后核对。
- 原文过时信息和疑似错误按原意翻译。仅对已可靠核实且会误导实际操作的内容增加明确标记、可追溯的“更新说明”；不静默替换原文，也不对每句话另建事实核查流程。
- 教程缺少环境、版本材料或文字稿时明确披露。可中文化已取得文字；没有运行验证就不声称代码可独立运行。不补写不存在的课程材料或练习答案。

## 制作流程

通过Codex小批次读取原文、制作或修订中文稿、检查完整页面并接页。暂不启用现有API翻译器批量生成。具体模型和批次大小按文章长度、实际质量和工具条件安排；不固定全站统一篇数，不预设多代理或多模型认证流程。

已有稿件先检查，合格内容保留，明确问题局部修订，大面积误译或遗漏才重做。基础概念可优先处理以统一后续表达，但不把完整概念库、先修图谱或通用知识装配器作为生产前置。

每批只携带当前原文、统一规范、必要术语和具体未决问题。记录完成页面、问题位置、下一步及需要续接的文件；交接按[项目工作流](E:/dev/projects/AIHero/docs/agents/workflow.md)保存。出现实质问题才返工，修正后核对受影响部分；不为措辞无限润色。

## 必要工程改动

1. 整合现有[本地化规范](E:/dev/projects/AIHero/content/pilots/v2/STYLE_GUIDE.md)和[展示约定](E:/dev/projects/AIHero/content/learning/shared/display-conventions.md)中的有效内容，形成一个简短的现行规范入口。以上产品要求优先，旧固定模型分工、每篇必加词典等要求不自动沿用。
2. 提供一个可复用的本地接页入口，接受目标route、对应来源、已检查中文文件与可选页面辅助配置。复用现有解析与更新逻辑；无需复制文章专属脚本或改变页面数据源。
3. 接页前完成配置、来源、内容结构和链接检查。更新中文文件、索引、manifest及确有必要的辅助记录时，只修改本次目标，保留其他页面及共享记录；失败不留下部分更新。提供写入前预览及可恢复方式，具体脚本组织在实施时确定。
4. manifest记录来源和译稿哈希、实际制作及检查状态。接页成功不等于内容审查或浏览器验收通过，不填写未经执行的验收声明。
5. 复用现有检查脚本，补齐当前使用状态的译稿及索引一致性检查；检查新增中文Prompt时保留原代码与原Prompt，避免把合法新增示例误报为代码篡改。

已确认的实现依据：

- [assemble-agents-md-page.mjs](E:/dev/projects/AIHero/scripts/assemble-agents-md-page.mjs)可复用正文解析与目标更新，但当前硬编码文章，并在写入后校验部分来源，需调整。
- [publish-sample.mjs](E:/dev/projects/AIHero/scripts/publish-sample.mjs)覆盖整个索引，不可直接用于全站逐篇接入。
- [translate-content.mjs](E:/dev/projects/AIHero/scripts/translate-content.mjs)禁止新增说明，重建索引时只收录一种状态；可参考来源选择与哈希逻辑，不直接承担本轮生产。
- [article-learning.ts](E:/dev/projects/AIHero/lib/article-learning.ts)支持没有教学配置的文章；普通正文可继续使用现有页面，不要求全站迁入统一教学结构。

## 实施顺序与验收

| 阶段 | 交付与可观察的结果 |
| --- | --- |
| 1. 来源与规范 | 完成一次来源同步，保存范围与缺口；制作任务可以从一个规范入口取得当前要求，无需重读历史实验。 |
| 2. 安全接页 | 同一入口能接入不同文章；错误来源或无效配置被拒绝，原数据不变；成功时目标页更新、其他页面保留。 |
| 3. 三类样本 | 检查系统提示词、AGENTS.md指南、Output教程的完整中文页面，修复实质内容和接页问题。记录五项检查结论及缺项，形成可复用批次说明。 |
| 4. 全站批次 | 每批完成选定页面并更新清单；缺项明确、可续接；最终核对固定来源范围、中文索引和页面覆盖一致。 |
| 5. 本地交付 | 提供明确启动和停止方式；首页、深层文章地址可打开和刷新，范围内页面完整中文化，已披露来源缺口及未验证运行项。 |

每篇使用同一组五项检查：

1. **信息完整准确**：对照原文逐节检查，无关键遗漏、误译、观点或条件改变。
2. **中文自然**：通读中文稿，消除影响阅读的翻译腔和歧义，术语使用一致。
3. **必要概念讲清**：陌生关键概念有简短解释或可用中文词条，新增说明身份明确，篇幅适度。
4. **代码与链接保真**：原代码、命令、配置及英文Prompt保留；中文版Prompt完整可复制；中文页面和原资源链接去向正确。
5. **页面正常显示**：真实打开最终页面，核对正文、代码、链接和适用的复制、折叠、术语交互；首批及公共展示改动检查桌面与窄屏，无异常横向滚动。后续复用未受影响的展示证据，检查新内容特有结构。

语义检查由制作执行者对照原文与中文稿完成并记录。脚本验证结构和数据，不能替代内容判断；构建成功不能替代真实页面检查。无需每篇安排真人试读或独立模型认证，已有或后续用户反馈按具体问题处理。

工程验证包括目标更新隔离、失败无写入、已有页面保留的相关测试，以及已有内容校验与构建。公共渲染改动检查受影响样本。历史31项lint报错仅为此前快照，实施时核对相关基线并修复本次引入的问题；全仓lint清零、CI建设不作为本规格的独立扩展项目。

## 边界与依赖

不建设AI对话、独立课程、学习能力评分、知识审计平台或自动调度平台；不统一迁移所有历史研究资产。不把旧三阶段、12维度、先修依赖闭包或双份执行包变成每篇固定要求。

来源同步后的新增、变化和缺失需要实际核对，不能沿用历史覆盖率。教程运行准备尚未验证的部分按具体页面披露。此前开发服务有遗留状态阻碍启动的记录；本地交付时需检查当前启动行为，必要时修正项目自身状态处理，不能按历史PID结束无关程序。

后续来源更新按需进行，只处理新增或变化页面；先核对原文差异，再更新中文稿并重新检查受影响内容。
